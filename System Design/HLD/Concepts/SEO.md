# ✅ Essential SEO Optimization Techniques (For Interviews)

## 🧱 On-Page SEO

- **Title Tags**: Use primary keywords, keep under 60 characters.
- **Meta Descriptions**: Summarize content with keywords (150–160 characters).
- **Header Tags**: Use semantic headings (`<h1>` to `<h3>`) with keywords.
- **Keyword Usage**: Naturally place primary and secondary keywords.
- **Image Optimization**: Use `alt` tags and compress images.
- **Internal Linking**: Link related pages to improve crawlability and user experience.
- **Clean URLs**: Short, readable, and keyword-rich (use hyphens).

## ⚙️ Technical SEO

- **Page Speed**: Minify files, lazy load images, use CDN.
- **Mobile-Friendly Design**: Responsive layout and accessible UI.
- **HTTPS**: Use SSL for secure site access.
- **XML Sitemap**: Helps search engines index pages.
- **Fix Broken Links**: Avoid 404s to maintain link equity.

## 🔗 Off-Page SEO

- **Backlinks**: Get links from high-authority, relevant sites.
- **Social Sharing**: Improve visibility and potential backlink opportunities.

## 🧠 Content SEO

- **High-Quality Content**: Original, valuable, and intent-focused.
- **Content Updates**: Refresh old content to keep it relevant.
